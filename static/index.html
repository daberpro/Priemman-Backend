Priemman API Documentation

Dokumentasi lengkap REST API backend Priemman — autentikasi (OTP & OAuth), profil pengguna, proyek, koleksi, media, alur upgrade creator, dan endpoint admin. Semua request/response menggunakan binary Protobuf (package priemman.v1), dengan contoh payload dalam format JSON dan definisi proto di setiap endpoint.

  • Base URL: http://localhost:8080 (origin halaman ini)
  • Wire format: application/x-protobuf (binary Protobuf), kecuali disebutkan lain
  • Auth: header Authorization: Bearer <session_token> atau cookie session
  • Rate limit: 60 request/menit per IP → 429 + header Retry-After + proto Result{code:RATE_LIMITED}
  • Error: semua error berupa proto Result berisi error_detail{code,message,meta}
  • Timestamp: field google.protobuf.Timestamp ter-decode sebagai {seconds, nanos} → new Date(Number(seconds) * 1000)

Endpoints

Klik endpoint untuk melihat deskripsi, parameter, contoh request/response (tab JSON = ekuivalen proto3 JSON, Proto = definisi message, cURL = contoh pemanggilan), dan daftar error. Legenda: AUTH = butuh session token, ADMIN = khusus role admin.
